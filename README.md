# CompassionScroll — Animal Welfare Web Application

CompassionScroll is an animal-welfare-focused web application built with React and Vite. Its frontend dependencies include Supabase and Firebase integrations, interactive maps, and animated UI components.

## Project Overview

The repository contains the frontend application for an animal welfare experience. The project is structured around a modern React single-page application and includes libraries for backend integration, routing, mapping, and interface interactions.

## Technology Stack

- **React 19** and **React DOM** — user interface.
- **Vite** — local development server and production build tooling.
- **Supabase JS** — Supabase application integration.
- **Firebase** — Firebase services integration.
- **React Router** — client-side navigation.
- **Leaflet** and **React Leaflet** — interactive maps.
- **Framer Motion** — UI animations.
- **Tailwind CSS** — utility-first styling.
- **Lucide React** — interface icons.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/priyanshukannaujiya/Compassionscroll.git
cd Compassionscroll
npm install
```

### Start the development server

```bash
npm run dev
```

### Create a production build

```bash
npm run build
```

### Run the linter

```bash
npm run lint
```
